# TAH-RAG 校园交通治理结项演示系统

**[下载演讲电脑完整安装包（ZIP）](https://github.com/tyanshang-ai/campus-traffic-tah-rag-demo/raw/refs/heads/main/tah-rag-presentation.zip)** · [详细安装说明](演讲电脑安装说明.md)

用于笔记本现场展示，支持 Windows 10/11 和 macOS。程序、前端完整源码、论文和项目知识快照均在安装包中。无需本地大模型或独立显卡；GLM 问答需要网络和单独配置的接口密钥。

## 演讲电脑安装

1. 安装 Python 3.10+，建议 3.11 或 3.12；Windows 安装时勾选 **Add python.exe to PATH**。
2. 点击上面的完整安装包链接，完整解压并进入 `tah-rag-presentation` 文件夹。
3. Windows 双击 `首次安装.bat`；macOS 双击 `首次安装.command`，等待安装完成。
4. 用文本编辑器打开新生成的 `.env`，填写私下取得的 `TAH_GLM_API_KEY`。其他配置保留默认值。
5. Windows 双击 `启动演示.bat`；macOS 双击 `启动演示.command`。浏览器通常打开 **http://127.0.0.1:8877**，以启动窗口显示的地址为准，并保持该窗口开启。

安装包不含接口密钥。无密钥时可以浏览资料、查看历史方案及使用“资料摘录”；联网大模型问答须完成密钥配置。macOS 隐藏文件可用 Command+Shift+. 显示；详细权限与安装问题见安装说明。请提前在演讲电脑完成一次问答、来源引用和历史方案演练。

仓库直接提供可下载安装包；完整源码位于 ZIP 内。使用 **Code → Download ZIP** 时，请继续解压里面的 `tah-rag-presentation.zip`。

## 展示内容

- 项目成果：1707 张原项目知识卡、2742 个图谱节点、74514 条关系、4321 条历史决策。
- 知识库问答：GLM Coding Plan 接口，当前配置 `glm-5.3-flash`；回答附知识卡引用，可打开原卡和来源。
- 历史方案：按动作和点位筛选，查看已有观测、治理动作、理由并进行追问。
- 关联图谱：浏览实际节点与关系，选择节点高亮关联。
- 文档管理：导入 PDF、TXT、Markdown、DOCX；运行记录可在本机导出。

## 实现与资料范围

问答使用中文字符 TF-IDF 检索和 GLM 接口生成，图谱读取原项目关系。该交付包用于既有成果展示，没有新增大模型训练，也不代表完整复现论文算法或实验指标。场景推演为独立功能演示，未连接真实交通设备。

原项目规则为程序与模板生成，尚未核准为正式校园规定。历史结果未保存的检索证据编号及最终图验证字段保持缺失标记；当前相关检索与原历史证据分开展示。

资料包括已授权发布的论文、知识卡、图谱和聚合历史方案快照。不包含原始人员/车辆日志、模型权重、原系统密钥、运行日志或本机上传资料。

GLM 专用地址为 `https://open.bigmodel.cn/api/coding/paas/v4`，不会自动切换到按量地址。接口使用应符合平台套餐适用范围；详见包内操作手册与[官方套餐 FAQ](https://docs.bigmodel.cn/cn/coding-plan/faq)。
